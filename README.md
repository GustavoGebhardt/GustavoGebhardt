# Gustavo Gebhardt

**Desenvolvedor full stack — Java, TypeScript e Python.**
Construo a camada que faz sistemas existentes poderem ser operados por linguagem natural.

Na Climber RMS liderei o **Climber RMS MCP**, que tornou uma plataforma de revenue
management hoteleiro operável por texto: o que antes exigia navegar telas e conhecer
o sistema por dentro passou a poder ser pedido em uma frase.
Hoje curso Análise e Desenvolvimento de Sistemas no IFRS.
